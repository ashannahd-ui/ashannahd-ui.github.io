# Ashannah Darlene — Portfolio

A responsive personal portfolio website for Ashannah Darlene, a first-year Bachelor of Science in Computer Science student at Uganda Christian University (UCU).

## Files
- `index.html` — portfolio content
- `style.css` — layout, colors, and responsive styling
- `.nojekyll` — helps GitHub Pages publish the site as expected

## Publish with GitHub Pages
1. Download and unzip this folder.
2. Sign in to GitHub and open your profile: https://github.com/ashannahd-ui
3. Create a new repository. A simple name is `ashannahd-ui.github.io` (the repository name must match your GitHub username exactly, followed by `.github.io`, for a user-site URL).
4. Upload `index.html`, `style.css`, `README.md`, and `.nojekyll` directly into the repository's root folder. Do not upload the outer folder itself.
5. Open the repository's **Settings** → **Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then press **Save**.
7. Wait a few minutes. Your site should appear at `https://ashannahd-ui.github.io/`.

## Personalise it
- In `index.html`, edit the text to update your introduction, education, projects, or contact details.
- Replace the GitHub profile link if your username changes.
- Add your email or LinkedIn URL when you want to share them publicly.
- To add a photo, place an image file in this folder and update the HTML. Avoid adding private contact information you don't want public.

## Add future projects
Copy the `project-card` block in the Projects section and replace the title, description, and technology tags with details about your new project.
