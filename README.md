3. To edit it, open index.html in a plain-text code editor (for example, Visual Studio Code).

PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in to https://github.com (create a free account if needed).
2. Create a new repository named exactly: ashannahdarlene.github.io
   If that exact repository name is unavailable, choose a different repository name and follow GitHub Pages project-site instructions instead.
3. In the repository, choose Add file → Upload files, then upload index.html.
4. Commit the changes.
5. Open Settings → Pages. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save (if this option is shown).
6. Wait a few minutes. The site address for the exact repository name above should be:
   https://ashannahdarlene.github.io/
